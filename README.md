# AcaTalkLab

학원친구 독립 테스트 도구의 공개 배포 저장소입니다.

[최신 Windows ZIP 다운로드](https://github.com/animochoi-2026/AcaTalkLab/releases/latest/download/AcaTalkLab-windows-x64.zip) · [버전별 변경 사항](https://github.com/animochoi-2026/AcaTalkLab/releases)

1. 실행 중인 이전 테스트 도구를 종료합니다.
2. ZIP을 폴더째 풀고 `학원친구_테스트.vbs`를 실행합니다.
3. 0.1.6부터 GitHub 가입·로그인·접속 토큰 없이 자동 업데이트합니다.

0.1.5 이하에서 토큰 없이 사용 중이면 새 ZIP을 한 번 받아 실행해 주세요. 학원친구 자체 로그인은 기존 계정을 사용합니다.

공개 배포 파일에는 이 테스트 도구의 EXE·VBS·검증 정보만 포함합니다. 원본 학원친구 앱, 로그인 정보, 오류 로그, 사용자 이미지는 포함하지 않습니다.
